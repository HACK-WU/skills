## 跨包硬规则（各包都受其约束，不重复写）

- **证据三轨**：写法缺失 → `🟢`（代码即证据）；时序 / 组合 → `🟡` + `[需运行验证]`，复现升 `🟢`；不可静态确定 → `🔴` 只进待确认并给验证方法（细则见 02「判定与证据」）
- **预算**：每页 ≤6 条假设、每批复现 ≤10 条；写不出复现步骤的不算发现
- **边界**：只收"能在用户操作路径上表现"的缺陷；性能归 06，纯代码整洁归 `code-review`，安全只报前端可见面
- **报告只有一张清单**：包里的表格都是同一份清单的展开，不另出第二张
