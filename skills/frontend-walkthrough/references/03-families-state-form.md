# 细则 03｜缺陷族 2–5：状态一致性 / 生命周期副作用 / 表单输入 / 边界·计算·展示

> **何时读**：阶段 1.5 预筛命中族 2 / 3 / 4 / 5（表单页、列表页、详情页几乎必中其中之一）。
> 每条都问"哪种真实输入 / 状态下就坏"，判据与证据轨见 [02-timing.md](02-timing.md) 的「判定与证据」。

## 族 2｜状态一致性（同一个事实被存了两份、或绕过了框架的更新机制）

2a. 残留与复用
- 弹窗关闭未 reset：表单值、错误提示、勾选带到下一次打开
- 同路由不同参数复用组件实例（`/detail/1` → `/detail/2`）残留上一条数据（Vue 未 `watch route` 重取、React `key` 未变）
- `keep-alive` / `activated` 未刷新，回来看到过期数据
- 分页 / 筛选不随上下文重置（改筛选后仍停在第 2 页）
- 全局 store 的"当前选中项"跨页面残留 → 操作对象错位

2b. 真值与来源
- 同一数据存两份（`list` 与 `total`、原始与格式化、组件 state 与 store）→ 改一处忘另一处
- 直接改对象 / 数组（`push`、`obj.x =`）不触发渲染，或本该批量却逐条渲染
- 受控 / 非受控混用：`value` 无 `onChange` 变只读；`defaultValue` 之后不再跟随 props
- 依赖旧值更新（`setCount(count + 1)` 连点只加一次；应用函数式更新）
- 初始值只在首次取（`useState(props.x)`），props 后到不同步
- 派生状态手写缓存与源不一致（筛选项 + 过滤后结果各存一份）
- 真值留在 DOM / ref 里（勾选读 DOM 属性），UI 与数据脱节

## 族 3｜生命周期与副作用（建立了但没拆、或依赖没写对）

- 效应依赖缺失或过宽：读到旧值 / 自激循环（效应里 setState 又依赖该 state）
- 顺序假设错：父效应先于子效应、挂载前读 DOM、`ref` 未就绪
- 卸载 / 路由离开后仍写状态或发请求（泄漏、告警）
- 定时器 / 监听 / 订阅 / 观察者未清理 → 越用越卡、回调重复触发
- 条件渲染导致卸载重建：输入框失焦、视频重播、iframe 与表格滚动位置丢失
- 列表 `key` 用 index：删除或排序后组件内部状态（展开、输入、勾选）串位
- 单例 / 全局对象累积（地图、编辑器、WebSocket 重复创建）
- 副作用不幂等（StrictMode 双执行暴露；生产偶发重复上报）

## 族 4｜表单与输入（规则对不上、时机不对、输入比你想象的脏）

- 前端校验与后端不一致（前端放行后端 400 / 前端拦住后端允许）
- 异步校验未完成即可提交；或校验结果乱序覆盖
- 校验只做在提交时：定位不到字段、不知道错在哪
- 输入法（IME）组合态触发 `onChange` / 回车 → 半截拼音被提交或提前提交
- 粘贴带格式 / 首尾空格 / 全角 / emoji（长度、截断、后端字段长度）
- 数字：负数、小数位、超大值、科学计数法、千分位、空串与 `0` 不分
- 上传：类型与大小只看扩展名、多文件部分失败、中断无重试、无进度与取消
- 成功后不清表单 / 不清校验 / 不禁用 → 二次提交；失败后已填内容丢失
- 必填与禁用组合冲突（禁用字段不提交但校验要求必填 → 永远提交不了）
- 浏览器自动填充 / 密码管理器覆盖预填值；粘贴不触发校验

## 族 5｜边界、计算与展示

5a. 数据形态
- `res.data.list.map(...)` 但 `list` 缺失 → 白屏 / 报错
- HTTP 200 但 `code !== 0` 未判断 → 把失败当成功
- `null` / `undefined` / 空串直接渲染 → 界面出现 `null`
- 数值字段是字符串 → `"1" + 1 = "11"`、`total - 1` 变 `NaN`
- `0` / `''` 用 falsy 判断走错分支（`total=0` 显示"—"、空输入被判为未填）
- 时间字段非法 / 时区不符 → `Invalid Date`、差 8 小时
- 金额浮点累加、大整数精度丢失

5b. 计算与业务规则
- 金额 / 数量 / 百分比 / 折扣算错（浮点比较、四舍五入方向、先除后乘的精度损失）
- `if` 条件反转或漏 `else`，把"未选中"当"已选中"
- 状态机非法迁移未拦（已完成还能再提交、已删除还能编辑）
- 枚举 / 字典映射错位（状态码 2 显示成"已完成"），前后端枚举不一致
- 单位 / 时区 / 币种换算错，历史数据按新规则重算
- 排序 / 分页 / 过滤条件拼错 → "看到的不是查到的"
- 数量边界：0、负数、超库存、小数件数

5c. 展示与格式化
- 长文本截断后无法看全文（无 tooltip / 展开）
- 千分位、单位（万 / 亿）、精度在展示与存储间不一致
- 空态 / 加载态 / 骨架屏切换闪烁，首屏先闪"暂无数据"
- 表格：列宽挤压、固定列遮挡、横向滚动后表头错位、操作列换行
- 图表：空数据、负值、单位缺失、图例与系列对不上
- 图片：加载失败无占位、防盗链 403、比例失调
- 富文本 / HTML 展示未处理换行、外链、代码块
