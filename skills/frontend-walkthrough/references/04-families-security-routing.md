# 细则 04｜缺陷族 6–7：权限与安全 / 导航与路由

> **何时读**：阶段 1.5 预筛命中族 6 / 7（后台管理、任何有角色与深链的页面）。
> 安全只报前端可见面与写法缺口，**不构造利用链、不做渗透**；可利用性标"待评估"。

## 族 6｜权限与安全（只报前端可见面与写法缺口，不做渗透）

- 前端把校验当安全边界：价格、数量、角色、归属由前端传，后端照单全收
- 权限只隐藏不拦截：接口仍可调；控件用 `visibility` / `display:none` 仍可被 Tab 聚焦触发（应卸载）
- 路由直达绕过入口：手输 URL / 改 query 进无权限页，页面自身不校验
- 越权可见：接口返回全量，前端按角色过滤——数据早已到浏览器
- XSS 面：`v-html` / `innerHTML` / `dangerouslySetInnerHTML` / 富文本预览接用户输入且未转义
- 敏感信息落地：token、手机号、身份证进 localStorage / URL / 日志 / 埋点
- 跳转白名单缺失（`?redirect=` 被改成外站）；`target="_blank"` 无 `rel="noopener"`
- 文件预览 / 下载信任扩展名（上传 HTML / SVG 后同源预览）
- 认证态处理：401 只弹提示不跳登录，或刷新 token 死循环

## 族 7｜导航与路由

- history 模式刷新 404（服务端未配 fallback）
- 深链缺参 / 非法参（直接进 `/order/` 或 `/order/abc` 崩溃或空白）
- 返回后状态丢失：筛选、分页、滚动位置、展开项回到初始
- 守卫重定向死循环（无权限 → 首页 → 又判无权限）
- URL 编码：中文、`+`、空格、`&`、超长 query 被截断
- 同路由不同参数不重新取数（`/detail/1` → `/detail/2`）
- 弹窗与路由不同步：关弹窗没退路由；刷新后弹窗消失（分享链接失效）
- 新窗口打开依赖内存态 → 上下文丢失
