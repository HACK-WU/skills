# 实时/推送/消息类 推演策略

> 适用特征：长连接、消息推送、实时通知、消息队列消费
> 启用信号：WebSocket/推送/通知/消息队列/订阅/实时

## 精选验证维度

| 维度 | 本 profile 重点关注点 |
|------|----------------------|
| 异常覆盖 | 断线/超时/连接泄漏处理 |
| 幂等性 | 消费端幂等；重复推送安全 |
| 并发正确性 | 消息顺序；并发消费一致性 |
| 边界处理 | 背压/限流；订阅过期清理 |

## 加压点

- **连接管理**：断线重连、心跳保活、连接泄漏/上限
- **消息顺序保证**：顺序敏感场景下乱序如何处理（全局序号？分区内有序？）
- **消息丢失/重复**：至少一次/至多一次/恰好一次语义是否明确并实现
- **背压与限流**：消费慢于生产时背压策略；限流准确性
- **订阅过期/清理**：过期订阅是否清理；离线消息保留策略
- **幂等消费**：重复消息是否幂等处理

## 典型异常/边界清单

- 断线丢消息
- 重复推送
- 消息乱序
- 连接泄漏导致连接数耗尽
- 消费积压雪崩

## mermaid 提示

- `sequenceDiagram`：消息生产→投递→消费时序，标注丢失/重复/乱序风险点
- `flowchart TD`：连接生命周期（建连→心跳→断线→重连）
