# 重构/迁移类 推演策略

> 适用特征：系统重构、数据迁移、接口改造、灰度上线
> 启用信号：重构/迁移/灰度/兼容/双写/回滚/改造

## 精选验证维度

| 维度 | 本 profile 重点关注点 |
|------|----------------------|
| 决策可行性 | 迁移/灰度方案是否可行；回滚路径是否成立 |
| 异常覆盖 | 灰度炸雷/迁移失败/回滚失败处理 |
| 数据完整性 | 迁移数据完整可校验；双写一致性 |
| 边界处理 | 停机窗口；新旧并存期边界 |

## 加压点

- **新旧兼容**：向后兼容（旧端读新数据）+ 向前兼容（新端读旧数据）
- **回滚方案**：回滚是否可逆、是否需要数据回滚、回滚窗口
- **灰度炸雷**：灰度比例递增策略；灰度暴露问题如何快速止血
- **双写一致性**：双写任一端失败如何处理；对账与修复
- **数据迁移完整性**：迁移后数据量/校验和可核验；增量追平切流时机
- **停机窗口**：停机时间是否可接受；超时预案

## 典型异常/边界清单

- 回滚失败无法恢复
- 灰度暴露严重问题但无快速止血
- 双写不一致无对账
- 迁移丢数据/重复数据
- 兼容性破坏导致旧端崩溃

## mermaid 提示

- `flowchart TD`：灰度/回滚分支决策树
- `sequenceDiagram`：迁移步骤时序（全量→增量→切流→清理）
