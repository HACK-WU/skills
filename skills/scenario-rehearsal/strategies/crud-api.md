# CRUD/接口类 推演策略

> 适用特征：以增删改查/接口暴露为主，无复杂状态流转或跨步事务
> 启用信号：接口以 CRUD 命名、RESTful 资源、列表/详情/表单类功能

## 精选验证维度（从通用维度表精选）

| 维度 | 本 profile 重点关注点 |
|------|----------------------|
| 接口满足度 | 参数类型/返回值/异常是否完整；分页/排序/过滤参数是否完备 |
| 边界处理 | 分页越界、空结果、超大页、单条 vs 批量 |
| 幂等性 | 创建/删除是否幂等；重复提交是否安全 |
| 数据完整性 | 软删/硬删语义；唯一约束；外键级联 |

## 加压点（在通用维度上额外深挖）

- **重复创建幂等**：相同请求重复提交是否产生重复数据（按业务键去重？）
- **越权访问**：能否访问/修改他人数据（数据归属校验）
- **分页边界**：page 超界、pageSize 上限、offset 极大值性能
- **批量操作上限**：批量删除/更新是否有数量上限与原子性保证
- **并发更新覆盖**：读-改-写竞态是否用乐观锁/版本号保护

## 典型异常/边界清单

- 重复提交 → 重复创建
- 越权访问他人数据
- 分页越界返回异常
- 并发更新相互覆盖（丢失更新）
- 软删后唯一约束冲突（历史数据占位）
