# 并发/竞态敏感类 推演策略

> 适用特征：高并发、共享资源竞争、竞态敏感
> 启用信号：并发/竞态/锁/原子/缓存一致性/限流/秒杀

## 精选验证维度

| 维度 | 本 profile 重点关注点 |
|------|----------------------|
| 并发正确性 | 锁粒度/死锁/竞态窗口/原子性/可见性 |
| 幂等性 | 重复请求在并发下是否安全 |
| 边界处理 | 超卖/超限；限流穿透 |
| 数据完整性 | 多级缓存与 DB 一致性 |

## 加压点

- **锁粒度与死锁**：锁范围是否过粗（影响吞吐）或过细（竞态）；是否存在死锁/活锁路径
- **竞态窗口**：检查-执行之间是否存在时间窗（TOCTOU）
- **原子性**：复合操作是否原子（如扣减库存+写日志）
- **可见性**：多级缓存/多副本下写后读一致性；缓存失效时序
- **超卖/超限**：库存/名额并发扣减是否原子；是否有预扣/最终校验
- **限流准确性**：限流器在并发下是否准确；时钟漂移影响

## 典型异常/边界清单

- 超卖/超限
- 死锁/活锁
- 竞态导致更新丢失
- 缓存与 DB 不一致
- 限流穿透（并发下超放）

## mermaid 提示

- `flowchart TD`：并发竞争路径，标注竞态窗口与锁点
- `sequenceDiagram`：多请求竞争同一资源时序，标注死锁/超卖点
