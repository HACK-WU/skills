# Disable Task Delegation（关闭任务分级委派）

## 规则声明

**本规则生效时，`task-delegation` 规则自动失效。**

主 Agent 退回全包模式：

| 场景 | 行为 |
|------|------|
| 所有辅助任务（测试、文档、多轮工具调用、信息收集） | 由主 Agent 亲自执行，不委派子 Agent |
| 子 Agent 相关约定（委派模板、输出契约、兜底流程） | 全部不适用 |
| 用户在会话中明确要求"使用子 Agent" | 例外，按用户即时指令执行 |

## 使用场景

- 当前环境无法调用独立 AI（子 Agent 不可用）
- 项目任务量小，委派反而增加开销
- 需要主 Agent 完整掌握所有上下文（如敏感/机密任务，不宜外发）
- 用户希望全程透明、亲历所有执行细节

## 互斥声明

- 本规则与 `task-delegation` 规则**互斥**，二者同时存在时以本规则为准。
- **安装约定**：两个规则文件不应同时部署到同一工作区。默认只安装 `task-delegation`；需要关闭时，用本规则覆盖（替换或追加），而非并存。若不慎并存，按本规则优先处理。
- 若后续重新启用委派机制，需**移除或停用本规则文件**（或用户明确声明"恢复委派机制"），`task-delegation` 规则即恢复默认生效。

## 恢复方式

1. 删除/重命名本规则文件；或
2. 用户明确指令"恢复委派机制"，本规则的声明即不再适用。
