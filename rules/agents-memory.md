# Agents Memory

## 规则

AI 在对话过程中**必须使用 `AGENTS.md` 文件**作为临时记忆文件，主动记录以下信息：

| 记录类别 | 记录内容 |
|----------|----------|
| 项目架构 | 项目目录结构、模块划分、技术栈、依赖关系 |
| 需求进度 | 当前需求描述、完成状态、待办事项、阻塞问题 |
| 关键代码 | 核心函数/方法、重要算法、配置参数、API接口 |
| 决策记录 | 技术选型、设计决策、权衡考虑、替代方案 |
| 问题追踪 | 已知Bug、待解决问题、性能瓶颈、优化建议 |

## 执行流程

### 第一步：识别记录时机

在以下场景中**自动触发记录**：

1. **架构讨论**：分析项目结构、模块关系时
2. **需求分析**：理解或拆分需求时
3. **代码审查**：阅读或修改关键代码时
4. **问题解决**：调试错误、优化性能时
5. **决策制定**：选择技术方案、设计模式时

### 第二步：记录到 AGENTS.md

使用以下格式记录信息：

```markdown
## [记录类别] 记录时间

### 具体内容

- 要点1
- 要点2

### 相关代码

\`\`\`language
// 关键代码片段
\`\`\`

### 参考信息

- 文件路径: `path/to/file`
- 行号范围: 123-456
```

### 第三步：维护与更新

1. **去重检查**：记录前检查是否已存在相同信息
2. **版本更新**：更新已有记录时保留历史版本
3. **分类整理**：定期整理记录，按类别重组
4. **清理过期**：删除已完成的需求或已解决的问题

## 记录模板

### 项目架构记录

```markdown
## [架构] 2026-07-07

### 目录结构

- `/src`: 源代码目录
  - `/components`: React组件
  - `/services`: 业务逻辑
  - `/utils`: 工具函数

### 技术栈

- 前端: React + TypeScript
- 后端: Node.js + Express
- 数据库: PostgreSQL

### 模块依赖

```
前端 → API → 服务层 → 数据层
```
```

### 需求进度记录

```markdown
## [需求] 2026-07-07

### 当前需求: 用户认证系统

- [x] 登录功能
- [x] 注册功能

### 关键代码记录

```markdown
## [代码] 2026-07-07

### 核心函数: authenticateUser

```typescript
async function authenticateUser(email: string, password: string): Promise<User> {
  // 1. 验证邮箱格式
  // 2. 查询用户记录
  // 3. 比对密码哈希

  // 5. 返回用户信息

## 例外

以下情况**不记录**或**特殊处理**：

1. **用户明确禁止**：用户说"不要记录"、"忽略此信息"
2. **敏感信息**：密码、密钥、个人隐私数据（需脱敏处理）
3. **临时调试**：仅用于当前调试的临时信息
4. **重复内容**：与已有记录完全相同的信息
5. **无效信息**：与项目无关的闲聊或测试内容

## 注意事项

1. **保持简洁**：记录应精炼，避免冗余
2. **结构清晰**：使用标题、列表、代码块等格式
3. **及时更新**：信息变化时立即更新记录
4. **安全优先**：不记录敏感信息，必要时进行脱敏
5. **用户确认**：重要记录可询问用户是否需要保存
